# CodeJudge Database System - Part 2

This repository contains Part 2 of the SQL & DBMS Assignment: SQL Query Implementation & Verification.

### Included Files:
* `queries.sql`: Contains all 20 SQL queries divided into Basic, Joins, Aggregation, and Subqueries, with in-line comments.
* `query_outputs.md`: Detailed documentation of query purposes, sample outputs, and validation notes verifying dataset logic.
* `sql_reasoning.md`: Markdown answers explaining specific SQL concepts (Joins, HAVING vs. WHERE, subqueries, and edge cases).
